Real Estate Management System
====================================

Веб-приложение для управления объектами недвижимости с админ-панелью на базе **Orchid Platform**.
Система позволяет управлять жилыми комплексами, зданиями, секциями, этажами и помещениями (квартирами), отслеживать их статусы, характеристики и историю изменений.


Требования для установки
----------

*   Docker
*   Make
*   Git



Установка
---------

 Клонировать репозиторий:

```Bash
git clone https://github.com/justbepanda/RealEstateManagmentSystem.git
```

Выполнить установку и поднятие окружения через Make:

```Bash
make setup
```

Make setup выполнит:

*   Сборку контейнеров Docker

*   Установку зависимостей Composer

*   Настройку базы данных

*   Прогон миграций и сидеров


Доступ к админ-панели: http://localhost:8000/admin/main

Демо юзер:

name: `Admin`

email: `admin@admin.com`

password: `password`

Функциональность
----------------

### Жилые комплексы

*   CRUD операции (создание, редактирование, удаление, просмотр)

*   Название, описание, адрес, статус (planning, construction, completed)

*   Галерея изображений

*   Координаты для отображения на карте


### Здания

*   CRUD операции

*   Принадлежат комплексам

*   Номер/название, количество этажей, год постройки


### Секции

*   CRUD операции

*   Принадлежат зданиям

*   Номер/название, количество этажей


### Этажи

*   CRUD операции

*   Принадлежат секциям или зданиям

*   Номер, количество квартир, план этажа (изображение)


### Помещения (квартиры)

*   CRUD операции

*   Принадлежат этажам

*   Номер квартиры, тип помещения (apartment, studio, penthouse, commercial)

*   Количество комнат, площадь (общая, жилая, кухня)

*   Статус (available, reserved, sold, not\_for\_sale)

*   Цены (базовая, со скидкой, за м²)

*   Планировка (изображение), галерея

*   Дополнительные характеристики (балкон, лоджия, вид из окна и т.д.)


### Админ-панель (Orchid)

*   Screens для CRUD операций

*   Filters для фильтрации данных

*   Charts для визуализации статистики

*   Кастомные виджеты для дашборда

*   Экран Dashboard с графиками продаж, топ-10 дорогих помещений и статистикой по комплексам


### История изменений

*   Логирование изменений статусов и цен

*   Учет пользователя и времени изменений


### REST API (опционально)

*   Получение списка помещений с фильтрацией

*   Детальная информация о помещении

*   Статистика по комплексам


Производительность
------------------

*   Кэширование списков комплексов, зданий, секций

*   Кэширование статистики на дашборде (TTL 15-30 минут)

*   Тегированный кэш для инвалидации при изменениях

*   Кэширование результатов фильтрации


Тестирование
------------

*   Factories для генерации тестовых данных

*   Seeder для демонстрационных данных:

    *   2–3 комплекса с полной иерархией (здания → секции → этажи → помещения)

    *   50–100 помещений для проверки фильтрации
